Prediction markets

Trade YES and NO shares on sample events. A share pays $1.00 if its outcome happens and $0 if not, so the price reads as the market-implied probability. Prices come from an automated market maker (LMSR).

What the full build includes

This demo runs entirely in the browser on paper money. The production version keeps the same screens and adds the server side, real accounts and regulated partners. Scope below is a plan, not a commitment to dates or licenses.

Architecture

Web appNext.js (React, TypeScript), server-rendered pages, the trading screens from this demo
Admin consoleSame codebase, role-based access, audit log of every operator action
HTTPS / WebSocket
API serviceNode.js: accounts, orders, positions, margin checks, prediction markets
Price serviceNode.js: connects to data providers, normalizes quotes, fans out over WebSocket
Risk workerMark-to-market, margin calls, stop-out, settlement jobs
SQL / pub-sub
PostgreSQLUsers, ledger (double-entry), orders, markets, audit trail
RedisLive quotes cache, sessions, rate limits, job queue
Provider APIs
KYC providerIdentity documents, liveness, sanctions screening (e.g. Sumsub, Onfido, Persona)
Crypto paymentsDeposit addresses and payouts by a licensed processor (e.g. Fireblocks, BitGo, Coinbase Prime)
Liquidity / brokerReal execution for live accounts through a regulated counterparty

Demo and live accounts use separate ledgers. Live trading is switched on per region only after the legal review for that region.

Four-week plan

  1. Week 1Project setup, database schema and ledger, authentication, price service with free feeds, trading screens connected to the API in paper mode.
  2. Week 2Order engine (market, limit, TP/SL), margin and liquidation worker, account and risk pages, admin console with roles and audit log.
  3. Week 3Prediction markets on the server (LMSR market maker, limit orders, combos, resolution workflow), commodity tools, notifications.
  4. Week 4KYC and crypto payment provider integration in sandbox mode, region rules (US and EU leverage caps and disclosures), load and security testing, deployment.

Going live with real money depends on provider contracts and legal approval in each target region. That work runs alongside the build and is outside the four weeks.

What stays the same

Every calculation shown in this demo (leverage, liquidation price, fees, LMSR pricing, margin level) is written as a separate engine with its own tests. The full build reuses that engine on the server, so the formulas behind the numbers in this demo are the ones the server runs.
