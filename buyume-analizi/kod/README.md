# Büyüme teşhisi (örnek)
1. `python uret_ornek_veri.py` — hayali online eğitim şirketi için örnek CSV'ler (ornek-veri/).
2. `python analiz.py [veri_klasoru] [cikti.js]` — kanal/huni/dönüş hızı/temsilci/sayfa analizi + aksiyon listesi -> ../veri.js.
Gerçek müşteride GA4, Google/Meta/TikTok Ads ve CRM dökümleri aynı sütunlara eşlenir; sayfa (index.html) veri.js'i okur.
